# Recognizer

**Linux үшін дауыстан мәтінге енгізу құралы** — пернені басып тұрыңыз, сөйлеңіз, жіберіңіз — мәтін курсор орнында пайда болады.

[Русский](Readme.ru.md) | [English](Readme.md) | [Українська](Readme.uk.md) | [日本語](Readme.ja.md) | [中文](Readme.zh.md) | [العربية](Readme.ar.md)

## Мүмкіндіктер

- **Push-to-talk жазу** — жазу үшін F9 басып тұрыңыз, тану үшін жіберіңіз
- **Лезде қою** — танылған мәтін автоматты түрде курсор орнына қойылады
- **Ақылды қою** — терминалдарда автоматты түрде Ctrl+Shift+V, басқа қосымшаларда Ctrl+V пайдаланады
- **Алмасу буферін сақтау** — буфер мазмұны сақталады және қойғаннан кейін қалпына келтіріледі
- **Дыбыстық кері байланыс** — жазуды бастау/аяқтау кезінде ксилофон дыбысы
- **Нұсқау сөз тіркестерін ауыстыру** — алмасу буферінің мазмұнын қою үшін «мынау» немесе «осы» деп айтыңыз
- **Көп тілді сөз тіркестер** — орыс, ағылшын, украин, қазақ, жапон, қытай және араб тілдерінде
- **Баптауға болатын модель** — `.env` арқылы кез келген OpenAI транскрипция моделін таңдау

## Талаптар

- X11 бар Linux
- Go 1.21+
- PortAudio кітапханасы
- OpenAI API кілті

## Орнату

### 1. Тәуелділіктерді орнатыңыз

```bash
# Ubuntu/Debian
sudo apt install portaudio19-dev libx11-dev libxtst-dev libxinerama-dev libxcursor-dev libxkbcommon-dev

# Fedora
sudo dnf install portaudio-devel libX11-devel libXtst-devel libXinerama-devel libXcursor-devel libxkbcommon-devel

# Arch
sudo pacman -S portaudio libx11 libxtst libxinerama libxcursor libxkbcommon
```

### 2. Клондау және құрастыру

```bash
git clone https://github.com/makhnanov/recognizer.git
cd recognizer
cp .env.example .env
```

### 3. Баптау

`.env` файлын өңдеп, параметрлерді орнатыңыз:

```
OPENAI_API_KEY=sk-...
WHISPER_MODEL=gpt-4o-transcribe
WHISPER_LANGUAGE=kk
```

- `OPENAI_API_KEY` — сіздің OpenAI API кілтіңіз (міндетті)
- `WHISPER_MODEL` — транскрипция моделі (әдепкі: `gpt-4o-transcribe`)
- `WHISPER_LANGUAGE` — тіл кеңесі ISO-639-1 форматында (міндетті емес, мысалы `kk`, `ru`, `en`)

### 4. Құрастыру

```bash
make
```

Немесе қолмен:

```bash
go build -o recognizer recognizer.go
```

## Қолдану

```bash
./recognizer
```

- **F9 басып тұру** — жазуды бастау (дыбыстық сигнал)
- **F9 жіберу** — жазуды тоқтату, тану және қою (дыбыстық сигнал)
- **Ctrl+C** — шығу

### Нұсқау сөз тіркестері

Нұсқау сөз тіркестері `phrases.txt` файлынан жүктеледі (әр жолда бір сөз тіркесі, `#` жолдары — түсініктемелер). Файл әр транскрипция кезінде қайта оқылады, сондықтан бағдарламаны қайта іске қоспай өңдеуге болады.

Бірнеше тілде сөз тіркестері дайын: орыс, ағылшын, украин, қазақ, жапон, қытай және араб.

Мысал: Кодты көшіріңіз, содан кейін «Мынаны түзет» деп айтыңыз → «Мынаны [буфер мазмұны]» қойылады

## Автоматты іске қосу

Recognizer жүйеге кірген кезде автоматты түрде іске қосылуы үшін жұмыс үстелі файлын көшіріңіз:

```bash
cp scripts/recognizer.desktop $HOME/.config/autostart/ # If executor in /var/www/recognizer/recognizer
```

## Қайта құрастыру және қайта іске қосу

Ағымдағы данасын тоқтату, қайта құрастыру және фонда іске қосу үшін:

```bash
./scripts/restart.sh
```

Скрипт жұмыс істеп тұрған процесті тауып тоқтатады, жаңа бинарник құрастырады және оны терминалдан ажыратып іске қосады. Шығыс `recognizer.log` файлына жазылады.

## Терминал бүркеншік аттары

`~/.bashrc` немесе `~/.zshrc` файлына қосыңыз:

```bash
alias rec='/жол/recognizer'
```

## Бұл қалай жұмыс істейді

1. Жүйелік хуктар арқылы F9 перне оқиғаларын тыңдайды
2. Әдепкі микрофоннан WAV файлына аудио жазады
3. Аудионы OpenAI транскрипция API-ге жібереді (баптауға болатын модель)
4. Мәтінді өңдейді (соңындағы көп нүктені алып тастайды, `phrases.txt` файлынан нұсқау сөз тіркестерін ауыстырады)
5. Белсенді терезе түрін анықтап, нәтижені Ctrl+Shift+V (терминалдар) немесе Ctrl+V (басқа қосымшалар) арқылы қояды, бастапқы алмасу буферін сақтайды
