# Recognizer

**Linux үшін дауыстан мәтінге енгізу құралы** — пернені басып тұрыңыз, сөйлеңіз, жіберіңіз — мәтін курсор орнында пайда болады.

[Русский](Readme.ru.md) | [English](Readme.md) | [Українська](Readme.uk.md) | [日本語](Readme.ja.md) | [中文](Readme.zh.md) | [العربية](Readme.ar.md)

## Мүмкіндіктер

- **Push-to-talk жазу** — жазу үшін F9 басып тұрыңыз, тану үшін жіберіңіз
- **Лезде қою** — танылған мәтін автоматты түрде курсор орнына қойылады
- **Алмасу буферін сақтау** — буфер мазмұны сақталады және қойғаннан кейін қалпына келтіріледі
- **Дыбыстық кері байланыс** — жазуды бастау/аяқтау кезінде ксилофон дыбысы
- **Нұсқау сөз тіркестерін ауыстыру** — алмасу буферінің мазмұнын қою үшін "вот это" деп айтыңыз

## Талаптар

- X11 бар Linux
- Go 1.21+
- PortAudio кітапханасы
- OpenAI API кілті

## Орнату

### 1. Тәуелділіктерді орнатыңыз

```bash
# Ubuntu/Debian
sudo apt install portaudio19-dev libx11-dev libxtst-dev libxinerama-dev libxcursor-dev libxkbcommon-dev

# Fedora
sudo dnf install portaudio-devel libX11-devel libXtst-devel libXinerama-devel libXcursor-devel libxkbcommon-devel

# Arch
sudo pacman -S portaudio libx11 libxtst libxinerama libxcursor libxkbcommon
```

### 2. Клондау және құрастыру

```bash
git clone https://github.com/makhnanov/recognizer.git
cd recognizer
cp .env.example .env
```

### 3. Баптау

`.env` файлын өңдеп, OpenAI API кілтіңізді қосыңыз:

```
OPENAI_API_KEY=sk-...
```

### 4. Құрастыру

```bash
make
```

Немесе қолмен:

```bash
go build -o recognizer recognizer.go
```

## Қолдану

```bash
./recognizer
```

- **F9 басып тұру** — жазуды бастау (дыбыстық сигнал)
- **F9 жіберу** — жазуды тоқтату, тану және қою (дыбыстық сигнал)
- **Ctrl+C** — шығу

### Нұсқау сөз тіркестері

"вот это", "вот эта", "вот сюда" сияқты сөз тіркестерін айтқанда, олар ағымдағы алмасу буферінің мазмұнына ауыстырылады. Бұл диктант кезінде көшірілген мәтінге сілтеме жасауға мүмкіндік береді.

Мысал: Кодты көшіріңіз, содан кейін "Исправь вот это" деп айтыңыз → "Исправь [буфер мазмұны]" қойылады

## Терминал бүркеншік аттары

`~/.bashrc` немесе `~/.zshrc` файлына қосыңыз:

```bash
alias rec='/жол/recognizer'
```

## Бұл қалай жұмыс істейді

1. Жүйелік хуктар арқылы F9 перне оқиғаларын тыңдайды
2. Әдепкі микрофоннан WAV файлына аудио жазады
3. Тану үшін аудионы OpenAI Whisper API-ге жібереді
4. Мәтінді өңдейді (соңындағы көп нүктені алып тастайды, нұсқау сөз тіркестерін ауыстырады)
5. Нәтижені Ctrl+V арқылы қояды, бастапқы алмасу буферін сақтайды
