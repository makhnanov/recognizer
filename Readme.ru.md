# Recognizer

**Голосовой ввод текста для Linux** — зажми клавишу, говори, отпусти — и текст появится в позиции курсора.

[English](Readme.md) | [Қазақша](Readme.kk.md) | [Українська](Readme.uk.md) | [日本語](Readme.ja.md) | [中文](Readme.zh.md) | [العربية](Readme.ar.md)

## Возможности

- **Push-to-talk запись** — зажмите F9 для записи, отпустите для распознавания
- **Мгновенная вставка** — распознанный текст автоматически вставляется в позицию курсора
- **Умная вставка** — автоматически использует Ctrl+Shift+V в терминалах, Ctrl+V в остальных приложениях
- **Сохранение буфера обмена** — содержимое буфера сохраняется и восстанавливается после вставки
- **Звуковая обратная связь** — звук ксилофона при начале/окончании записи
- **Подстановка указательных фраз** — скажите «вот это» для вставки содержимого буфера обмена
- **Мультиязычные фразы** — указательные фразы на русском, английском, украинском, казахском, японском, китайском и арабском
- **Фильтр негатива** — автоматически переписывает грубую или оскорбительную речь вежливым языком (настраиваемый порог)
- **Настраиваемая модель** — выбор любой модели транскрипции OpenAI через `.env`

## Требования

- Linux с X11
- Go 1.21+
- Библиотека PortAudio
- API-ключ OpenAI

## Установка

### 1. Установите зависимости

```bash
# Ubuntu/Debian
sudo apt install portaudio19-dev libx11-dev libxtst-dev libxinerama-dev libxcursor-dev libxkbcommon-dev

# Fedora
sudo dnf install portaudio-devel libX11-devel libXtst-devel libXinerama-devel libXcursor-devel libxkbcommon-devel

# Arch
sudo pacman -S portaudio libx11 libxtst libxinerama libxcursor libxkbcommon
```

### 2. Клонируйте и соберите

```bash
git clone https://github.com/makhnanov/recognizer.git
cd recognizer
cp .env.example .env
```

### 3. Настройте

Отредактируйте `.env` и задайте параметры:

```
OPENAI_API_KEY=sk-...
WHISPER_MODEL=gpt-4o-transcribe
WHISPER_LANGUAGE=ru
FILTER_MODEL=gpt-4o-mini
NEGATIVITY_THRESHOLD=50
```

- `OPENAI_API_KEY` — ваш API-ключ OpenAI (обязательно)
- `WHISPER_MODEL` — модель транскрипции (по умолчанию: `gpt-4o-transcribe`)
- `WHISPER_LANGUAGE` — подсказка языка в формате ISO-639-1 (необязательно, например `ru`, `en`)
- `FILTER_MODEL` — модель для анализа негативности (по умолчанию: `gpt-4o-mini`)
- `NEGATIVITY_THRESHOLD` — порог негативности в процентах для переписывания (по умолчанию: `50`, `0` — отключить)

### 4. Соберите

```bash
make
```

Или вручную:

```bash
go build -o recognizer recognizer.go
```

## Использование

```bash
./recognizer
```

- **Зажать F9** — начать запись (звуковой сигнал)
- **Отпустить F9** — остановить запись, распознать и вставить (звуковой сигнал)
- **Ctrl+C** — выход

### Указательные фразы

Указательные фразы загружаются из файла `phrases.txt` (по одной фразе на строку, строки с `#` — комментарии). Файл перечитывается при каждой транскрипции, поэтому его можно редактировать без перезапуска программы.

Из коробки включены фразы на нескольких языках: русском, английском, украинском, казахском, японском, китайском и арабском.

Пример: Скопируйте код, затем скажите «Исправь вот это» → вставится «Исправь [содержимое буфера]»

## Автозагрузка

Чтобы Recognizer запускался автоматически при входе в систему, скопируйте файл автозагрузки:

```bash
cp scripts/recognizer.desktop $HOME/.config/autostart/ # If executor in /var/www/recognizer/recognizer
```

## Пересборка и перезапуск

Для остановки текущего экземпляра, пересборки и запуска в фоне:

```bash
./scripts/restart.sh
```

Скрипт находит и останавливает запущенный процесс, собирает новый бинарник и запускает его отвязанным от терминала. Вывод пишется в `recognizer.log`.

## Алиасы для терминала

Добавьте в `~/.bashrc` или `~/.zshrc`:

```bash
alias rec='/путь/к/recognizer'
alias рек=rec  # для русской раскладки
```

## Как это работает

1. Слушает события клавиши F9 через системные хуки
2. Записывает аудио с микрофона по умолчанию в WAV-файл
3. Отправляет аудио в API транскрипции OpenAI (настраиваемая модель)
4. Обрабатывает текст (убирает многоточие в конце, подставляет указательные фразы из `phrases.txt`)
5. Анализирует негативность текста — если превышает порог, переписывает вежливо
6. Определяет тип активного окна и вставляет результат через Ctrl+Shift+V (терминалы) или Ctrl+V (остальные приложения), сохраняя исходный буфер обмена
