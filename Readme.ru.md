# Recognizer

**Голосовой ввод текста для Linux** — зажми клавишу, говори, отпусти — и текст появится в позиции курсора.

[Русский](Readme.ru.md) | [English](Readme.md) | [Қазақша](Readme.kk.md) | [Українська](Readme.uk.md) | [日本語](Readme.ja.md) | [中文](Readme.zh.md) | [العربية](Readme.ar.md)

## Возможности

- **Push-to-talk запись** — зажмите F9 для записи, отпустите для распознавания
- **Мгновенная вставка** — распознанный текст автоматически вставляется в позицию курсора
- **Сохранение буфера обмена** — содержимое буфера сохраняется и восстанавливается после вставки
- **Звуковая обратная связь** — звук ксилофона при начале/окончании записи
- **Подстановка указательных фраз** — скажите "вот это" для вставки содержимого буфера обмена

## Требования

- Linux с X11
- Go 1.21+
- Библиотека PortAudio
- API-ключ OpenAI

## Установка

### 1. Установите зависимости

```bash
# Ubuntu/Debian
sudo apt install portaudio19-dev libx11-dev libxtst-dev libxinerama-dev libxcursor-dev libxkbcommon-dev

# Fedora
sudo dnf install portaudio-devel libX11-devel libXtst-devel libXinerama-devel libXcursor-devel libxkbcommon-devel

# Arch
sudo pacman -S portaudio libx11 libxtst libxinerama libxcursor libxkbcommon
```

### 2. Клонируйте и соберите

```bash
git clone https://github.com/makhnanov/recognizer.git
cd recognizer
cp .env.example .env
```

### 3. Настройте

Отредактируйте `.env` и добавьте ваш API-ключ OpenAI:

```
OPENAI_API_KEY=sk-...
```

### 4. Соберите

```bash
make
```

Или вручную:

```bash
go build -o recognizer recognizer.go
```

## Использование

```bash
./recognizer
```

- **Зажать F9** — начать запись (звуковой сигнал)
- **Отпустить F9** — остановить запись, распознать и вставить (звуковой сигнал)
- **Ctrl+C** — выход

### Указательные фразы

Когда вы произносите фразы вроде "вот это", "вот эта", "вот сюда" и т.д., они заменяются на текущее содержимое буфера обмена. Это позволяет ссылаться на скопированный текст в диктовке.

Пример: Скопируйте код, затем скажите "Исправь вот это" → вставится "Исправь [содержимое буфера]"

Поддерживаемые фразы:
- вот это, вот эта, вот этот, вот эти, вот этого, вот этих
- вот такое, вот такая, вот такой, вот такие
- вот сюда, вот здесь, вот тут
- и их варианты с "вот" в конце (вот это вот, вот эта вот...)

## Алиасы для терминала

Добавьте в `~/.bashrc` или `~/.zshrc`:

```bash
alias rec='/путь/к/recognizer'
alias рек=rec  # для русской раскладки
```

## Как это работает

1. Слушает события клавиши F9 через системные хуки
2. Записывает аудио с микрофона по умолчанию в WAV-файл
3. Отправляет аудио в OpenAI Whisper API для распознавания
4. Обрабатывает текст (убирает многоточие в конце, подставляет указательные фразы)
5. Вставляет результат через Ctrl+V, сохраняя исходный буфер обмена
