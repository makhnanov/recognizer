# Recognizer

**Голосове введення тексту для Linux** — затисніть клавішу, говоріть, відпустіть — і текст з'явиться в позиції курсора.

[Русский](Readme.ru.md) | [English](Readme.md) | [Қазақша](Readme.kk.md) | [日本語](Readme.ja.md) | [中文](Readme.zh.md) | [العربية](Readme.ar.md)

## Можливості

- **Push-to-talk запис** — затисніть F9 для запису, відпустіть для розпізнавання
- **Миттєва вставка** — розпізнаний текст автоматично вставляється в позицію курсора
- **Розумна вставка** — автоматично використовує Ctrl+Shift+V у терміналах, Ctrl+V в інших програмах
- **Збереження буфера обміну** — вміст буфера зберігається і відновлюється після вставки
- **Звуковий зворотний зв'язок** — звук ксилофона при початку/закінченні запису
- **Підстановка вказівних фраз** — скажіть «ось це» для вставки вмісту буфера обміну
- **Багатомовні фрази** — вказівні фрази російською, англійською, українською, казахською, японською, китайською та арабською
- **Налаштовувана модель** — вибір будь-якої моделі транскрипції OpenAI через `.env`

## Вимоги

- Linux з X11
- Go 1.21+
- Бібліотека PortAudio
- API-ключ OpenAI

## Встановлення

### 1. Встановіть залежності

```bash
# Ubuntu/Debian
sudo apt install portaudio19-dev libx11-dev libxtst-dev libxinerama-dev libxcursor-dev libxkbcommon-dev

# Fedora
sudo dnf install portaudio-devel libX11-devel libXtst-devel libXinerama-devel libXcursor-devel libxkbcommon-devel

# Arch
sudo pacman -S portaudio libx11 libxtst libxinerama libxcursor libxkbcommon
```

### 2. Клонуйте та зберіть

```bash
git clone https://github.com/makhnanov/recognizer.git
cd recognizer
cp .env.example .env
```

### 3. Налаштуйте

Відредагуйте `.env` і задайте параметри:

```
OPENAI_API_KEY=sk-...
WHISPER_MODEL=gpt-4o-transcribe
WHISPER_LANGUAGE=uk
```

- `OPENAI_API_KEY` — ваш API-ключ OpenAI (обов'язково)
- `WHISPER_MODEL` — модель транскрипції (за замовчуванням: `gpt-4o-transcribe`)
- `WHISPER_LANGUAGE` — підказка мови у форматі ISO-639-1 (необов'язково, наприклад `uk`, `en`)

### 4. Зберіть

```bash
make
```

Або вручну:

```bash
go build -o recognizer recognizer.go
```

## Використання

```bash
./recognizer
```

- **Затиснути F9** — почати запис (звуковий сигнал)
- **Відпустити F9** — зупинити запис, розпізнати і вставити (звуковий сигнал)
- **Ctrl+C** — вихід

### Вказівні фрази

Вказівні фрази завантажуються з файлу `phrases.txt` (по одній фразі на рядок, рядки з `#` — коментарі). Файл перечитується при кожній транскрипції, тому його можна редагувати без перезапуску програми.

З коробки включені фрази кількома мовами: російською, англійською, українською, казахською, японською, китайською та арабською.

Приклад: Скопіюйте код, потім скажіть «Виправ ось це» → вставиться «Виправ [вміст буфера]»

## Автозавантаження

Щоб Recognizer запускався автоматично при вході в систему, скопіюйте файл автозавантаження:

```bash
cp scripts/recognizer.desktop $HOME/.config/scripts/
```

## Перезбірка та перезапуск

Для зупинки поточного екземпляра, перезбірки та запуску у фоні:

```bash
./scripts/restart.sh
```

Скрипт знаходить і зупиняє запущений процес, збирає новий бінарник і запускає його відв'язаним від терміналу. Вивід пишеться у `recognizer.log`.

## Аліаси для терміналу

Додайте до `~/.bashrc` або `~/.zshrc`:

```bash
alias rec='/шлях/до/recognizer'
```

## Як це працює

1. Слухає події клавіші F9 через системні хуки
2. Записує аудіо з мікрофона за замовчуванням у WAV-файл
3. Надсилає аудіо до API транскрипції OpenAI (налаштовувана модель)
4. Обробляє текст (прибирає три крапки в кінці, підставляє вказівні фрази з `phrases.txt`)
5. Визначає тип активного вікна і вставляє результат через Ctrl+Shift+V (термінали) або Ctrl+V (інші програми), зберігаючи вихідний буфер обміну
